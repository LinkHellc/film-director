# 七段式视频提示词模板

方法论第 5 步（PDF 第 11 页）原文模板。每个镜头一份，存成 `films/<片名>/shots/<镜头>/prompt-v<n>.txt`，文件里只放提示词本身。

```
【画风】[一句话写画风，比如：干净的现代 2D 手绘动画，平涂色块，线条利落，没有颗粒和纹理]。整段的画风、颜色、人物设计与首帧和尾帧完全一致。
【镜头】整段 [X] 秒，[景别]，[机位]，[运镜；不动就写“不推不拉不摇，不切镜”]。
【构图与配色】[人和东西在画面哪里，墙和光是什么颜色。要和首帧对得上]
【人物】[每个人的长相、衣服、固定道具，写死]
【逐秒】
0–0.2 秒：画面完全静止，和首帧一模一样。
[每一段：谁做什么，表情怎么变，手放在哪、不能碰什么，往画面哪边]
最后 0.3 秒：所有人完全停住，画面与尾帧完全一致。
【声音】只有 [看得见原因的声音]。人物不说话。
【约束】画面里一直只有首帧这几个人和这些东西，脸和身形全程不变，一镜到底。画面干干净净，没有文字、字幕、水印。
```

## 填写说明（本项目的约定）

- 【画风】用 G3 定下、记在 `requirements.md` 里的那句，全片每镜一字不差。
- 【镜头】的 X 写这一镜的计费秒数（分镜表"生成秒数"，最少 4 秒，mini 最多 15 秒），景别、机位、运镜照分镜表。
- 【构图与配色】位置写画面左右和大致比例（"人的眼睛在画面左起约 38%"），颜色用 `board/palette-v<n>.md` 色表里这一场的颜色，和首帧对得上。
- 【人物】照抄设定图的固定特征，固定东西写明位置（"纹身在左手臂上"）；数量写死（"只有一封黄信封"）。
- 【逐秒】每一段写清楚谁先谁后、动作的原因、手放在哪；方向按画面写（"朝画面左边走"）；每镜只写一两个主要动作；时间只是大概，多留一点余量。
- 【声音】只写看得见原因的声音；不配对白时写"人物不说话"。
- 写完对照 `pitfalls.md` 逐行查一遍，再送 `pre-submit` 审核。
