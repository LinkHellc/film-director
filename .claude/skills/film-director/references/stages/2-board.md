# 阶段 2：分镜——定镜头语言、构图和配色（`stage = "board"`）

方法论：这是整个前期最重要的一步，构图和配色决定片子的质量。有参考片就先逐帧看参考片，把机位、进出画比例量出来再模仿；没有就按下面的要求自己构思。每个镜头都要写清：景别、机位、运镜、谁往哪走（写画面左右）、靠什么表情推进、怎么转到下一镜。

## 做什么

### 1. 写分镜表 `board/storyboard-v<n>.md`

照方法论的提示词（原文）：

> 把定稿的故事写成分镜表。每个镜头一行，写清楚：片中时间（配歌就按小节算）、生成秒数（片中时长向上取整，尽量多留 0.5 秒）、景别、机位、运镜、谁往哪走（写画面的左右）、靠什么表情推进、这个镜头是什么在动、怎么转到下一个镜头。
>
> 如果有参考片，先逐帧看参考片，把机位、进出画比例这些都量出来，然后学习模仿。没有参考片就按下面的要求自己构思。
>
> 要求：
> 1. 每个镜头换角度。全片平视正面最多两次，其余用俯拍、仰拍、从背后、过肩、透过东西拍。
> 2. 画面里要一直有东西在动。大多数镜头都要有人或者东西走进画面，或者走出画面。人不走动的镜头，就让别的东西动起来，比如飘过去的一张纸，或者身后走过的路人。固定机位更要让人在画面里走动，比如从远处走到近处。
> 3. 不要连着好几个镜头都是一样大小的画面，全身、半身、脸部特写要换着来。
> 4. 每个镜头都要写清楚是什么在动：摄影机、焦点、光线、镜头前面飘过的东西，或者人物的小动作，至少要有一样。也不要一直动，该动的地方动，该静的地方静。
> 5. 镜头运动要有理由：跟着一个东西走，慢慢推近给特写，或者从近处慢慢拉远。
> 6. 每一秒截图都要好看。人的头或者眼睛落在画面从左往右大约 38% 或者 62% 的位置，不要放在正中间。

表格列（每镜一行，镜头号沿用 `story/shots-v<n>.md` 的 `S01`、`S02`……）：

| 镜头 | 片中时间 | 生成秒数 | 景别 | 机位 | 运镜 | 谁往哪走（画面左右） | 靠什么表情推进 | 这个镜头是什么在动 | 怎么转到下一个镜头 |
|---|---|---|---|---|---|---|---|---|---|

写完自己对一遍 6 条要求：数一数平视正面有几次；有没有连着同样景别；每镜"什么在动"是不是至少一样；运镜有没有理由。

### 2. 算时长：计费秒数

`quote.ts` 按 `state.shots.<镜头>.seconds`（片中时长）算计费秒数：向上取整；取整后余量不足（含等于）0.5 秒再加 1 秒；**最少按 4 秒计费**（网关下限）。mini 一段最长计费 15 秒（片中时长 14.4 秒以内），超了 `quote.ts` 会退出 2、提示"请拆镜头"，这时把这一镜拆成两镜。

| 片中时长 | 计费（生成）秒数 |
|---|---|
| 0.1–3.4 秒 | 4 |
| 3.5–4.4 秒 | 5 |
| 4.5–5.4 秒 | 6 |
| …… | …… |
| 13.5–14.4 秒 | 15（mini 上限，片中时长不要超过 14.4 秒） |

设计时长时要想到这个下限：片中只用 2 秒的镜头也按 4 秒付钱，所以要么把这一镜设计成 3–3.4 秒用足，要么在分镜里写明"生成 4 秒、后期剪出最好的 2 秒"。"生成秒数"一列写计费秒数，它也是七段式提示词【镜头】里的"整段 X 秒"。

### 3. 配色和色表 `board/palette-v<n>.md`

方法论（原文）：

> 配色要单独设计，在画第一张图之前定好。我想要的配色：[我的喜好；没想好就给我几个方案选]。
> 把每一场用什么颜色单独列成一张色表。

- 本人没说喜好：先给本人 2–3 个配色方案选（AskUserQuestion，`requirements.md` 关口编号写 `[配色]`）。
- 文件写：全片主色、强调色（后期调色时受保护）、肤色；再列色表——每一场一行：场、镜头范围、背景色、人物主色、强调色、光的颜色，都写色值（如 `#1d2a3a`）。这份文件是 `pre-submit` 审核的"配色规则"。

### 4. 色块草图和黑白检查

方法论（原文）：

> 最后用代码给每个镜头画一张 1920×1080 的色块草图，标出 38% 和 62% 的位置和主要的东西，拼成一张总表给我确认。再把草图转成黑白看一遍，如果人和背景区分不开，就说明明暗对比不明显，要重新调配色。

1. 写 `board/sketch-v<n>.json`（格式见 `scripts/py/sketch.py` 开头）：每镜一项，`bg` 是背景色，`blocks` 是主要的人和东西（x/y/w/h 是占画面的比例，人的头或眼睛放在 0.38 或 0.62 附近），颜色取自色表。
2. `.venv/Scripts/python scripts/py/sketch.py films/<片名>/board/sketch-v<n>.json films/<片名>/board/sketch-v<n>.png`
3. `.venv/Scripts/python scripts/py/grayscale.py films/<片名>/board/sketch-v<n>.png films/<片名>/board/sketch-v<n>-gray.png --board films/<片名>/board/sketch-v<n>.json`
   - 退出 0：明暗对比都够。
   - 退出 1：输出里列出的色块和背景分不开 → 改配色（新版本 `palette-v<n+1>.md`、`sketch-v<n+1>.json`），重画重查。
4. 用 Read 打开总表和黑白图自己看一遍。

### 5. 写 `state.shots`

按分镜表给每镜写一项（键是镜头号，`seconds` 是片中时长，不是计费秒数）：

```json
"shots": {
  "S01": { "seconds": 3.4, "status": "planned", "clip": null },
  "S02": { "seconds": 4.6, "status": "planned", "clip": null }
}
```

### 6. 问 G2

按 `../gates.md` 的 G2 问，附分镜表、色表、草图总表和黑白图。

## 产物

- `board/storyboard-v<n>.md`：分镜表（`keyframe-plan`、`pre-submit` 审核的资料）
- `board/palette-v<n>.md`：配色和色表（`pre-submit` 审核的资料）
- `board/sketch-v<n>.json`、`board/sketch-v<n>.png`、`board/sketch-v<n>-gray.png`：色块草图和黑白图

## 完成后 `state` 怎么改

`state.shots` 写好；G2 选了"分镜和配色定了"：`gates.G2 = "approved"`，`stage = "style"`，打开 `3-style.md`。
